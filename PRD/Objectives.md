# 🎯 Objetivos — Proyecto20-10

## 🎯 Objetivo general

Desarrollar una aplicación web full stack orientada a la gestión y organización de cursos, que permita a los usuarios administrar información y explorar recorridos de aprendizaje mediante una interfaz moderna, intuitiva y adaptable.

El proyecto busca combinar herramientas de desarrollo web actuales con una arquitectura modular y una experiencia de usuario basada en los principios de **Mobile First**.

## ✅ Objetivos específicos

### 📚 Gestión de cursos
- Implementar las operaciones CRUD para crear, consultar, editar y eliminar cursos.
- Facilitar la visualización y organización de la información.
- Incorporar paginación para mejorar la navegación entre los resultados.

### 🗺️ Roadmap de aprendizaje
- Explorar la recopilación de información de cursos de Udemy mediante técnicas de scraping, sujeto a las condiciones de uso aplicables.
- Diseñar una estructura que permita organizar cursos en recorridos de aprendizaje.
- Facilitar la consulta de cursos según su ubicación dentro de un recorrido, cuando esta funcionalidad se encuentre definida.

### 🔐 Autenticación y seguridad
- Implementar registro e inicio de sesión.
- Incorporar recuperación de contraseña.
- Aplicar mecanismos de limitación de solicitudes (*rate limiting*).
- Proteger las operaciones que requieran autenticación.

### 🎨 Experiencia de usuario
- Aplicar el enfoque **Mobile First**.
- Diseñar una interfaz clara, minimalista y consistente, inspirada en Google Material Design.
- Facilitar la navegación mediante un menú hamburguesa.
- Promover la reutilización de componentes de interfaz.

### 🏗️ Arquitectura e infraestructura
- Organizar el código por funcionalidades.
- Separar las responsabilidades del frontend, backend y base de datos.
- Utilizar Docker y Docker Compose para facilitar la configuración del entorno.

## 🏁 Resultado esperado

Contar con una aplicación web funcional, modular y mantenible, con autenticación, gestión de cursos y una base preparada para incorporar recorridos de aprendizaje.

## 📈 Criterios generales de éxito

- Las funcionalidades incluidas operan según los requisitos definidos.
- Los datos se almacenan de forma persistente.
- La interfaz se adapta a dispositivos móviles y pantallas de mayor tamaño.
- Los accesos y las operaciones protegidas se validan correctamente.
- El entorno de desarrollo puede configurarse siguiendo la documentación del proyecto.
