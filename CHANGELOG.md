# Changelog

Los cambios relevantes de Proyecto20-10 se documentan en este archivo.

El formato sigue las convenciones de Keep a Changelog y el versionado semántico.

## [v0.1.0] - 2026-10-27

### Added
- Scaffold del proyecto: estructura inicial de backend y frontend.
- Backend mínimo con FastAPI y endpoints GET /health y GET /cursos.
- Frontend mínimo con React y Vite, integrado con GET /cursos.
- Entorno de desarrollo con Docker Compose y PostgreSQL 18.6.
- Variables de entorno de ejemplo y documentación para iniciar el entorno.
